# 官方接口调研 · 2026-10-22

本插件只声明数据，不注册 AI 工具、不接收凭证，不自行联网。运行时兼容性由 Aide 的 providerSupport protocol 1 决定。

## 刊例价

[官方价格表](https://help.aliyun.com/zh/model-studio/model-pricing)按地域、部署范围、模型与单次输入 token 总量分档。分档采用整次请求计价，不是累进计价；K=1000，M=1000000。本版只收录北京端点的文本生成实时原价，不把名称相同的新加坡或美国模型当作北京价格，也不应用限时优惠。

[上下文缓存](https://help.aliyun.com/zh/model-studio/context-cache)分显式与隐式；显式创建可能高于普通输入费率，最新模型还存在例外比例。本版不猜测缓存折扣。显示金额是普通调用估算，不替代账单；免费额度、资源包、订阅计划、优惠与不同模态另计。

## 余额接口

[QueryAccountBalance](https://www.alibabacloud.com/help/en/user-center/developer-reference/api-bssopenapi-2017-12-14-queryaccountbalance)属于费用与成本 OpenAPI，不是模型推理接口。使用版本 2017-12-14 的 RPC 签名，需另配 AccessKey ID / AccessKey Secret，可带 STS SecurityToken。模型 API Key 不能替代这组身份凭证。接口返回 AvailableAmount（可用额度）、AvailableCashAmount（现金余额）和 Currency，不能把可用额度称作现金。

[官方端点](https://www.alibabacloud.com/help/en/user-center/developer-reference/api-bssopenapi-2017-12-14-endpoint)区分中国站 business.aliyuncs.com 与国际 business.ap-southeast-1.aliyuncs.com。本版只声明中国站。

[RAM 授权说明](https://help.aliyun.com/en/user-center/developer-reference/api-calling-authorization)支持最小只读 Action bssapi:QueryAccountBalance，Resource 为 *；兼容旧权限名 bss:DescribeAcccount（官方拼写）。请使用只授权此动作的 RAM 身份，不需要 AliyunBSSFullAccess。

Aide 必须把费用凭证单独放入加密 vault，显式配置后才查询；不从环境变量、插件设置、模型 API Key 或用户文件中猜测。请求固定官方 HTTPS 端点，不重定向，不向插件 JS 传凭证，不把签名查询串写日志。未配置时给出明确状态，不能伪造余额 0。

本轮没有使用真实 AccessKey、调用付费模型或查询真实账户余额。余额应通过本地合成响应与签名固定向量验收；真实账户验证由用户后续配置完成。
